Lesson plan (Module 1)

Use this page to guide the session. The content is written to match the demo site features.

Lesson flow (60–90 minutes)

Time Topic What students do
10 min HTML structure Identify header/main/footer and navigation on each page
15 min CSS tokens + reuse Edit :root variables and see changes across the site
15 min Selectors + states Inspect .card, input:focus-visible, :required:invalid
15 min DevTools Live-edit styles in Edge DevTools and take screenshots
15 min JavaScript basics Click Theme button, inspect event listeners, submit Contact form

Mini tasks (for practice)

CSS Tasks

  • Change --bg and --accent to create a new theme
  • Make the nav buttons larger using padding
  • Add input:hover style

HTML Tasks

  • Add a new page section using a <section> tag
  • Add an ordered list of steps for submitting the form
  • Add a new field to the contact form (e.g., phone)

Built for Module 1: HTML structure + CSS selectors + basic JavaScript + Edge DevTools.
