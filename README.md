# Module 1 – Full 5-Page Site (HTML + CSS + JavaScript)

## What you get
- 5 pages: Home, About, Lessons, Resources, Contact
- Shared `styles.css` (uses the ContactUs theme for the whole site)
- Shared `app.js` (nav highlighting, theme cycling, contact form success output)

## File list
- `index.html`
- `about.html`
- `lessons.html`
- `resources.html`
- `ContactUs.html`
- `styles.css`
- `app.js`

## Run options
### Option A (simple)
Open `index.html` in Microsoft Edge.

### Option B (recommended)
Use a local server (Live Server in VS Code, or Visual Studio static site). This avoids some browser security restrictions.

## Suggested lab activities
1. Change `--accent` and `--bg` in `:root`
2. Add a new nav item/page
3. Add a phone field to the contact form
4. Use DevTools to inspect CSS specificity
5. Add a new JS feature: character counter for the message textarea
