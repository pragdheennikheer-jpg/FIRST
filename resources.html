FAQ (interactive without JS)

Why aren’t my CSS variables changing anything?

Variables only affect the page when they are used with var(--name). Example: background: var(--bg);

How do I know my CSS file is loading?

Open DevTools → Network tab → refresh. You should see styles.css load with status 200.

Why does the browser block the form?

Because inputs use required and email uses type="email". That triggers built-in browser validation.
