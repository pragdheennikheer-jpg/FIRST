About this project

This site is intentionally small and readable. Students can inspect HTML structure, CSS selectors, and JavaScript events without being overwhelmed.

Semantic HTML

Each page uses <header>, <main>, and <footer> for structure.

  • Improves accessibility and readability
  • Helps screen readers navigate content
  • Makes layouts easier to reason about

Modern CSS

Your ContactUs theme is reused across the whole site.

  • Design tokens using :root variables
  • Responsive layout with media queries
  • Focus + validation states for forms

JavaScript (minimal on purpose)

Module 1 JS is kept beginner-friendly:

  • Highlights the current page in the navigation
  • Cycles theme accent colors (demonstrates DOM + events)
  • Handles contact form submit after built-in validation

Built for Module 1: HTML structure + CSS selectors + basic JavaScript + Edge DevTools.
